# Версионирование и совместимость

- Поле версии плагина: `plugin.yaml -> version`.
- При несовместимых изменениях API плагина поднимайте major.
- Для миграций добавляйте changelog внутри плагина и обновляйте docs.
- Рекомендуется тестировать плагин на текущей и предыдущей стабильной версии Neyra.
