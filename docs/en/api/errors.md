# Ошибки API

## Базовые коды
- `unauthorized`
- `not_found`
- `bad_request`
- `forbidden_update`
- `config_error`
- `openrouter_error`
- `internal_error`

HTTP статус соответствует типу ошибки (400/401/403/404/5xx).
